## 使用指南

### 1️. 创建黑名单

1. 点击"**创建黑名单**"标签页
2. 输入黑名单规模
3. 点击"**创建**"按钮
4. 等待创建完成，界面会显示：
   - 创建状态：已创建
   - 当前黑名单规模：XXXX条

**注意：** 重新创建会覆盖原有数据。

---

### 2️. 创建测试集

1. 点击"**创建测试集**"标签页
2. 输入库内规模（0-5000之间的整数）
3. 输入库外规模（0-5000之间的整数）
4. 确保：库内+库外 > 0
5. 点击"**创建**"按钮
6. 等待创建完成，界面会显示：
   - 创建状态：已创建
   - 测试集规模：XX个库内/XX个库外

**说明：**
- **库内数据**：从黑名单中随机抽取，查询应该匹配
- **库外数据**：随机生成的身份证号，查询应该不匹配

---

### 3️. 黑名单查询

1. 确保已完成"创建黑名单"和"创建测试集"
2. 点击"**黑名单查询**"按钮
3. 等待查询完成，界面会显示：
   - 查询状态：查询完成
   - 查询结果：XX条匹配/XX条测试
   - 查询耗时：XX秒

**查询逻辑：** 使用同态加密技术在不暴露明文的情况下进行匹配。

---

### 4️. 导出结果

1. 查询完成后，点击"**导出**"按钮
2. 系统会将结果导出为Excel文件
3. 文件命名格式：`测试集查询结果_YYYYMMDDHHmmss.xlsx`
4. 保存路径：系统会提示
